# Pradhan Mantri Simulator

## Game Design Bible --- Sprint 1 (Design Phase)

> **Project Status:** LOCKED MVP\
> **Rule #1:** This is a **game**, not a website.\
> **Rule #2:** No new gameplay features until MVP is complete.

------------------------------------------------------------------------

# Vision

Pradhan Mantri Simulator is a premium Indian political strategy
simulation game where the player becomes the Prime Minister of India and
makes meaningful decisions affecting the country's economy, popularity,
diplomacy, and elections.

Core Pillars: - Strategy over action - Consequences over randomness -
Indian identity - Premium mobile-first UI - High replayability

------------------------------------------------------------------------

# Target Platform

-   Primary: Mobile PWA
-   Secondary: Android App
-   Future: iOS

Tech Stack: - Next.js - TypeScript - Tailwind CSS - Framer Motion -
FastAPI - PostgreSQL / Supabase

------------------------------------------------------------------------

# Locked Gameplay Loop

Decision → Immediate Effects → News Generation → Public Reaction →
Country Stats Update → Random Event → Repeat

# UI / UX Philosophy

The UI must feel like a premium strategy game---not a dashboard website.

Reference direction: - Business Empire polish - Modern premium mobile
UI - Dark theme with gold accents - Interactive India map - Large "Take
Decision" CTA - Crisis cards - Bottom navigation - Smooth premium
animations

# Visual Style

Colors: - Deep Navy - Gold - Emerald - Crimson - Ivory

Animation: - Smooth - Heavy - Premium - Minimal but satisfying

------------------------------------------------------------------------

# Engine Philosophy

The player sees simple numbers.

The engine internally calculates: - Economy - Treasury - Popularity -
Inflation - Employment - Election probability

Every decision updates multiple hidden systems.
